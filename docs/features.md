# 機能要件

[要件定義書](./requirements.md) の詳細ドキュメント。FIT LOG の機能要件（機能一覧と決まりごと）をまとめる。

- 画面 ID（S-xx）は、次の段階で [画面仕様・画面遷移・ユースケース](./screens.md) で確定する。この文書の画面 ID は仮のもの
- API ID（A-xx）は [API 設計](./api.md) で、機能 ID（F-xx）と対応させて付ける
- 重量・距離・ペースは、この文書では kg・km で書く。画面では、ユーザーが選んだ単位で入力・表示する（[F-63](#設定)）
- 「見てよい投稿」は、[閲覧の制御](#閲覧の制御)の規則で判定した結果をいう。見てはいけない投稿は「存在しない」として扱う（404）

## 認証

前回の SNS アプリと同じ仕組みとする。

| ID | 機能名 | 内容 | 画面 |
|---|---|---|---|
| F-01 | 新規登録 | ユーザー名・表示名・メールアドレス・パスワードでアカウントを作る。登録後はそのままログイン状態にし、確認用のメールを送る（F-05） | S-02 |
| F-02 | ログイン | メールアドレスとパスワードでログインする | S-01 |
| F-03 | ログアウト | サーバーでリフレッシュトークンを無効にし、画面側のアクセストークンも捨てて、ログイン画面に戻る | 共通ヘッダー |
| F-04 | ログイン状態の復元 | 画面を開いたときに、リフレッシュトークンでアクセストークンを再発行してログイン状態を戻す。アクセストークン（15分）の期限が切れたら自動で再発行する | 全画面 |

ユーザー情報の項目：

| 項目 | 必須 | 決まり |
|---|---|---|
| ユーザー名（`@xxx`） | ○ | 半角英数字と `_`、4〜15文字。全ユーザーで重複不可（大文字・小文字は区別せずに判定する）。登録後は変更不可 |
| 表示名 | ○ | 1〜50文字。重複可。後から変更可 |
| メールアドレス | ○ | 全ユーザーで重複不可。ログインに使う。小文字にそろえて保存する。変更は F-06 |
| パスワード | ○ | 8〜72文字（BCrypt が72バイトまでしか扱えないため） |
| 自己紹介 | － | 160文字まで |
| アイコン画像 | － | 未設定なら、表示名の頭文字を丸の中に表示する |

## アカウント管理

| ID | 機能名 | 内容 | 画面 |
|---|---|---|---|
| F-05 | メールアドレスの確認 | 確認用のリンクを開くと、メールアドレスを「確認済み」にする。未確認の間は、画面の上に案内と「確認メールを再送」ボタンを出す | S-05、共通ヘッダー |
| F-06 | メールアドレスの変更 | 新しいメールアドレスと今のパスワードを入力すると、新しいアドレスに確認用のリンクを送る。リンクを開いたときに変更する（それまでは今のアドレスのまま） | S-50 |
| F-07 | パスワードの変更 | 今のパスワードと新しいパスワードを入力して変更する | S-50 |
| F-08 | パスワードのリセット | メールアドレスを入力すると、再設定用のリンクを送る。リンクを開いて新しいパスワードを決める | S-03, S-04 |
| F-09 | 退会 | パスワードを入力して退会する。本人のデータをすべて消し、ログイン画面に戻る | S-50 |

| 決まり | 内容 |
|---|---|
| 確認用のリンク | 有効期限は24時間。新しいリンクを送ると、前のリンクは使えなくなる |
| 再設定用のリンク | 有効期限は30分。1回だけ使える |
| リセットの応答 | 入力したメールアドレスが登録されているかどうかに関係なく、同じ応答（「メールを送りました」）を返す |
| リセットメールの送り先 | 登録されているメールアドレス（確認済みかどうかは問わない）。未確認のアドレスにも送る（確認前にパスワードを忘れた人が使えなくなるのを防ぐ） |
| メールの送信の上限 | 確認メール・リセットメールは、同じアドレスに1時間で5通まで。超えたときも、リセットの応答は同じにする |
| ログインの無効化 | パスワードの変更・リセットのあと、すべての端末のリフレッシュトークンを無効にする（変更した端末だけはログインしたままにする） |
| トークンの保存 | 確認用・再設定用のトークンはハッシュにして保存する |
| 退会で消すもの | 本人の投稿（画像・種目・セットを含む）・ナイストレーニング・コメント（ほかの人の投稿に付けたものも）・フォロー・フォローのリクエスト・通知（本人が受け取ったもの、本人の操作で作られたもの）・体重・目標・応援・テンプレート・自分専用の種目・トークン |
| 退会のあと | 同じメールアドレスで新しく登録できる。ユーザー名をすぐに使えるようにするかは未決定（[要件定義書 10章](./requirements.md)） |

## トレーニング記録（投稿）

| ID | 機能名 | 内容 | 画面 |
|---|---|---|---|
| F-10 | 記録の作成 | 実施日・ひとこと・トレーニング時間・種目とセット・画像・公開範囲を入力して投稿する | S-13 |
| F-11 | 記録の編集 | 自分の記録のすべての項目を変更できる（画像の追加・削除を含む）。一度でも編集した記録には「編集済み」と表示する | S-13 |
| F-12 | 記録の削除 | 自分の記録を削除する。確認ダイアログを出す。種目・セット・画像・ハッシュタグとの関連・ナイストレーニング・コメントも消える | S-10, S-12, S-40 |
| F-13 | 記録の詳細表示 | 記録1件（種目とセットの一覧・自己ベスト更新の印・画像）と、コメント一覧を表示する。本人には消費カロリーも表示する | S-12 |
| F-14 | 種目の検索 | 種目の名前の部分一致と部位で、最初から用意された種目と自分専用の種目を探す | S-13 |
| F-15 | 自分専用の種目の追加 | 名前・部位・記録方式を決めて、自分専用の種目を追加する | S-13 |
| F-16 | 自分専用の種目の編集・削除 | 名前・部位を変更する（記録方式は変えられない）。記録で使っていない種目だけ削除できる | S-13 |

記録の項目：

| 項目 | 必須 | 決まり |
|---|---|---|
| 実施日 | ○ | 初期値は今日（日本時間）。過去の日付は選べる。未来の日付は不可 |
| ひとこと | － | 280文字まで。`#` から始まる語はハッシュタグ（F-26） |
| トレーニング時間 | － | 1〜1440分。消費カロリーの計算に使う（F-86） |
| 種目 | ○ | 1〜20件。並び順を持つ。同じ種目を2回入れてもよい |
| セット | ○ | 種目ごとに1〜20件。並び順を持つ |
| 画像 | － | 4枚まで。JPEG・PNG・WebP。選べるのは1枚20MBまで。ブラウザで長い辺1600pxまで縮小してから送る。サーバーが受け付けるのは1枚2MBまで |
| 公開範囲 | ○ | 公開／フォロワー限定／自分のみ。初期値は「公開」 |

セットの項目（種目の記録方式で決まる）：

| 記録方式 | 項目 | 決まり |
|---|---|---|
| 重量 × 回数 | 重量 | 0.25〜500kg（0.25 刻み）。lb で入力するときは 0.5〜1100lb（0.5 刻み）。保存は kg で小数第3位まで |
| | 回数 | 0〜999回（0回は「挙がらなかった」セットとして記録できる。自己ベストには数えない） |
| 回数のみ | 回数 | 1〜9999回 |
| 時間・距離 | 時間 | 1秒〜24時間（時:分:秒で入力する）。保存は秒 |
| | 距離 | 任意。0.01〜500km（マイルで入力するときは 0.01 刻み）。保存は km で小数第3位まで |

- セットは、追加・削除・上下ボタンでの並べ替え・「前のセットを複製」ができる
- 種目は、追加・削除・上下ボタンでの並べ替えができる

種目（マスタ）：

| 項目 | 決まり |
|---|---|
| 名前 | 1〜30文字。最初から用意された種目と、自分専用の種目の中で、同じ名前は不可（大文字・小文字・全角半角は区別せずに判定する） |
| 部位 | 胸・背中・脚・肩・腕・腹・全身・有酸素 のどれか1つ |
| 記録方式 | 重量 × 回数／回数のみ／時間・距離 のどれか1つ |
| METs | 消費カロリーの計算に使う。最初から用意された種目は種目ごとに決める（値は [データ構造](./database.md) の初期データで決める）。自分専用の種目は、部位と記録方式から決めた標準の値を使う |
| ランニングかどうか | 最初から用意された種目のうち、ランニング・ジョギング・トレッドミルを「ランニング」とする。自分専用の種目はランニングにできない（集計の対象をはっきりさせるため） |

- 自分専用の種目は100件まで
- ほかのユーザーには、自分専用の種目は投稿に表示される名前としてだけ見える（検索の候補には出ない）

投稿カードに表示する内容（タイムライン・プロフィール・検索で共通）：

- 投稿者のアイコン・表示名・ユーザー名、実施日、投稿日時、公開範囲のアイコン、ひとこと、画像、ナイストレーニング数・付けたかどうか、コメント数、編集済みかどうか
- **種目の要約**（種目ごとに1行。5種目を超えたら「ほか N 種目」とまとめる）

| 記録方式 | 全セットが同じ値のとき | 値が違うとき |
|---|---|---|
| 重量 × 回数 | ベンチプレス 60kg × 10回 × 3セット | ベンチプレス 3セット（最大 70kg × 5回） |
| 回数のみ | 腕立て伏せ 20回 × 3セット | 腕立て伏せ 合計 55回（3セット） |
| 時間・距離 | ランニング 5.00km 30:00（6:00/km） | ランニング 合計 8.00km 50:00（2回） |

- 自己ベストを更新した種目には「自己ベスト更新」の印を付ける（F-85）
- 消費カロリーは、投稿カードにも他人にも表示しない（F-86）

## テンプレート・前回の記録の複製

| ID | 機能名 | 内容 | 画面 |
|---|---|---|---|
| F-17 | テンプレートの保存 | 名前を付けて、種目とセット（値を含む）を保存する。記録の作成画面の入力中の内容からも、自分の記録の詳細画面からも保存できる | S-12, S-13 |
| F-18 | テンプレートの管理 | テンプレートの一覧・名前の変更・中身の編集・削除 | S-14 |
| F-19 | テンプレート・前回の記録の呼び出し | 記録の作成画面でテンプレートを選ぶと、種目とセットを入力した状態にする。自分の記録の「この記録を複製」からは、その記録の種目とセットを入れた状態で作成画面を開く | S-12, S-13 |

- テンプレートの名前は1〜30文字。1人20件まで。種目とセットの数の決まりは記録と同じ
- 呼び出したときに入れるのは種目とセットだけ。実施日は今日、ひとこと・トレーニング時間・画像は空、公開範囲は初期値にする

- テンプレートは本人だけが見られる

## 閲覧の制御

すべての一覧・詳細・検索・ナイストレーニング・コメント・通知・画像の URL の発行で、次の規則で判定する。

| 投稿の公開範囲 | 投稿者が鍵アカウントでない | 投稿者が鍵アカウント |
|---|---|---|
| 公開 | ログインしている全員 | 投稿者本人と、承認済みのフォロワー |
| フォロワー限定 | 投稿者本人と、フォロワー | 投稿者本人と、承認済みのフォロワー |
| 自分のみ | 投稿者本人 | 投稿者本人 |

- 鍵アカウントでない人へのフォローは、すぐに「承認済み」になる。そのため、上の表の「フォロワー」はすべて「承認済みのフォロワー」と同じ意味になる
- ナイストレーニング・コメントは、その投稿を見られる人ならできる（「自分のみ」の投稿には本人だけができる）
- 見てはいけない投稿の詳細・ナイストレーニング・コメント・画像の URL の発行は、404 を返す
- 公開範囲を狭めても、付いたナイストレーニング・コメントは消さない。見られなくなった人には投稿ごと見えなくなる

## 投稿の検索

| ID | 機能名 | 内容 | 画面 |
|---|---|---|---|
| F-25 | ひとことの検索 | キーワードがひとことに含まれる投稿を探す | S-11 |
| F-26 | ハッシュタグ | ひとことの中のハッシュタグをリンクにする。押すと、同じハッシュタグの投稿の一覧を表示する | S-11, 投稿カード |
| F-27 | 種目での絞り込み | 選んだ種目を含む投稿だけを表示する | S-11 |

| 決まり | 内容 |
|---|---|
| キーワード | 前後の空白を取り除いて、1〜50文字。`%` `_` は普通の文字として扱う。英字の大文字・小文字は区別しない |
| ハッシュタグの形 | `#` の後に、文字（日本語・英字）・数字・`_`・`ー` が1〜30文字続くもの。1投稿で10個まで（それ以上はハッシュタグとして扱わない） |
| ハッシュタグの同一視 | Unicode の NFKC で正規化し（全角英数字を半角にそろえる）、英字を小文字にそろえて同じものとみなす |

| 種目の候補 | 最初から用意された種目と、自分専用の種目 |
| 対象と並び順 | 見てよい投稿だけを、投稿日時の新しい順に20件ずつ |

### 週間・月間の集計（F-80・F-81）

| 集計値 | 計算のしかた |
|---|---|
| トレーニング日数 | 記録がある日の数（1日に何件あっても1日） |
| 総挙上量 | 「重量 × 回数」のセットの、重量 × 回数の合計 |
| 運動時間 | 「時間・距離」のセットの時間の合計 |
| 距離 | 「時間・距離」のセットの距離の合計 |
| 消費カロリー | 記録ごとの消費カロリー（F-86）の合計。計算できなかった記録は含めず、「体重の記録がない日を除く」と表示する |
| 部位別のセット数 | 部位ごとのセット数と割合 |
| 前の期間との差 | 上の各値の、前の週（月）との差 |

- 週間の棒グラフ：曜日ごと（月〜日）に、総挙上量か運動時間かを切り替えて表示する
- 月間の推移グラフ：その月に含まれる週ごと（月曜始まり。月をまたぐ週は、その月の日だけを数える）
- 集計する週・月は、前後に移動して選べる。初期値は今週・今月

### ランニングの集計（F-83）

「ランニング」の種目のセットを対象に、週間・月間・年間で集計する。

| 集計値 | 計算のしかた |
|---|---|
| 走行距離 | 距離の合計 |
| 走行時間 | 時間の合計（距離のないセットも含む） |
| 回数 | セットの数（1セット ＝ 1回の走行） |
| 平均ペース | 距離のあるセットの、時間の合計 ÷ 距離の合計 |
| 最速ペース | 距離が 1km 以上のセットのうち、ペース（時間 ÷ 距離）が一番速い1回。同じなら距離が長い方、それも同じなら実施日が新しい方 |
| 最長距離 | 距離が一番長い1回。同じなら時間が短い方、それも同じなら実施日が新しい方 |

- 前の期間（前の週・月・年）との差を表示する
- 年間では、月ごとの走行距離の棒グラフを表示する
- 最速ペース・最長距離を押すと、その記録の詳細を開く
- マイル表示のときも、最速ペースの対象は「1km 以上」とする（判定は保存している km で行う）

### 種目ごとの推移（F-84）

| 記録方式 | 表示する値（実施日ごと） |
|---|---|
| 重量 × 回数 | 最大重量（1回以上挙げたセット）・最大の推定 1RM |
| 回数のみ | 合計回数・1セットの最大回数 |
| 時間・距離 | 合計時間・合計距離（ランニングはペースも） |

- 期間は 直近3か月・1年・全期間 から選ぶ
- 推定 1RM は Epley 式（重量 ×（1 + 回数 ÷ 30））で、回数が1〜10回のセットだけから計算する。回数が1回のセットは、重量そのものになる
- 選べる種目は、自分が1回以上記録した種目

### 自己ベスト（F-85）

- 「重量 × 回数」の種目で、回数が1回以上のセットの最大重量を、その種目の自己ベストとする
- **自己ベスト更新の印**：ある記録のある種目の最大重量が、それより前のすべての記録のその種目の最大重量を超えたときに付ける
  - 「前」は、実施日が前の記録と、同じ実施日で先に投稿した記録
  - その種目を初めて記録したときは付けない
  - 同じ記録に同じ種目が2回あるときは、2つをまとめた最大重量で判定し、最大重量を出した方に付ける
- 印は表示のたびに記録から計算する。記録を編集・削除すると、ほかの記録の印も変わる（あとの記録に印が付く・外れることがある）
- 他人の投稿の印も表示する。判定には、その人の非公開の記録も含める（印から非公開の記録の値は分からないため）

### 消費カロリー（F-86）

> 消費カロリー（kcal）＝ METs × 体重（kg）× 時間（時間）× 1.05

| 部分 | METs | 時間 |
|---|---|---|
| 有酸素（時間・距離の種目） | 種目の METs。ランニングで距離があるセットは、速さ（距離 ÷ 時間）に応じた METs（値は [データ構造](./database.md) の初期データで決める） | そのセットの時間 |
| 筋トレ（重量 × 回数・回数のみの種目） | その記録の筋トレの種目の METs を、セット数で重みづけた平均 | トレーニング時間 − 有酸素の時間の合計（0 以下なら筋トレの部分は 0） |

- 体重は、実施日以前で一番近い日の体重の記録を使う。1件もないときは計算せず、「体重を記録すると消費カロリーの目安が表示されます」と表示する
- トレーニング時間がない記録では、筋トレの部分を計算しない（有酸素の部分だけを表示し、その旨を書く）
- 整数（kcal）に四捨五入して表示する。「目安」であることを表示する
- **本人だけ**が見られる（記録の詳細とダッシュボード）。他人の API の応答には含めない

| 作れなかったとき | 通知を作れなくても、もとの操作は成功として扱う（失敗はログに残す） |
| 保存期間 | 未決定（[要件定義書 10章](./requirements.md)） |
